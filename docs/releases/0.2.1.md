# Spex Glance 0.2.1

A small follow-up to 0.2.0. Everyone on 0.2.0 should take this one.

## Fixes

- 0.2.0 reported itself as version 1.0 in About and in update checks, which made the app keep offering the 0.2.0 update to itself. Fixed; this build and every one after it carries the right version.
- The Work Mode shortcut is now ⌘⇧M. Plain ⌘M is macOS's own Minimize shortcut and won that fight. The Positions menu shows the new key.

## New

- A small "Kalshi Health" dot next to "Live" at the top of the window shows Kalshi's own status at all times: green when Kalshi reports itself up, ember when degraded, red when down, gray during maintenance. Hover it for the reason. Before, this only appeared when something was wrong, so a healthy Kalshi and a check that wasn't running looked the same.
